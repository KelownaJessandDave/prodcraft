# Vibe, Refined.

Static landing page for Vibe, Refined., a boutique product studio for AI-built products,
published from the Prodcraft repository and domain.

## Netlify deployment

Deploy this repository as a static site with no build command and `/` as the publish directory.
The project-interest form is detected automatically by Netlify Forms at deploy time.

The Meta Pixel is loaded only after a visitor selects **Allow analytics**. Consent is
stored in the browser, can be changed through **Cookie settings**, and is described on
`privacy.html`. Automatic Advanced Matching remains disabled.

After the first deployment, enable form submission notifications in Netlify under
**Project configuration → Notifications → Form submission notifications**.
